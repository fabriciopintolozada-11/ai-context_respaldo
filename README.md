# AI Context

Esta carpeta contiene la información de contexto que los asistentes de inteligencia artificial deben consultar para trabajar en el proyecto `pdis` de forma consistente.

## ¿Qué debe contener?

Aquí se pueden guardar documentos que expliquen:

- El objetivo y el alcance del proyecto.
- La arquitectura y los módulos principales.
- Las convenciones de código y nombres.
- Las reglas de negocio y decisiones técnicas.
- Los comandos habituales para ejecutar, probar o revisar el proyecto.
- Las tareas pendientes y las restricciones conocidas.

## Organización recomendada

Cuando se agreguen documentos, se recomienda usar nombres descriptivos y mantenerlos separados por tema. Por ejemplo:

```text
ai-context/
├── README.md
├── project-overview.md
├── architecture.md
├── coding-guidelines.md
└── decisions/
    └── 001-example.md
```

## Uso

Antes de modificar el código, el asistente debe revisar los documentos relevantes de esta carpeta. Los documentos deben mantenerse actualizados cuando cambien la arquitectura, las reglas del proyecto o los procesos de desarrollo.

Actualmente, esta carpeta solo contiene este archivo de referencia.
